# Kristendomen

Studiesida i religion för gymnasiet: kristendom samt tro och vetande. Allt på en sida med flikar, klickbara bilder, bokens frågor med svarsförslag, flashcards, quiz och sökbar ordlista. Ljust och mörkt läge.

Öppna sidan: `index.html` (eller via GitHub Pages).

## Kapitel

1. Jesus visar vem Gud är
2. En treenig Gud
3. Kyrkans riktningar
4. Att leva som kristen
5. Tro och vetande
6. Alla begrepp

Avsnitt märkta **Extra · ej från boken** är tillägg utöver läroboken.

## Bygga om

Sidan byggs från filerna i `atlas/kapitel/`:

```bash
python -I atlas/build.py
```
